# Friend Test Checklist

StudyShield was built for one real friend. This sheet captures **their genuine experience**, which is the strongest evidence the project solves a real problem.

**Never invent, polish or paraphrase their words.** Don't coach them toward a particular answer. Leave a blank question blank.

## Before the session

- [ ] Ask permission to quote them, and how they want to be named (first name, initials or anonymous).
- [ ] They use **their own** lecture notes (a text-based PDF).
- [ ] Give them their own student ID, separate from demo and test IDs.
- [ ] Let them drive. Watch, take notes, and only help if they're stuck.

## Suggested session (20–30 minutes)

1. Upload notes → Analyze
2. Look at the Concept Graph
3. Check "What should I study next?"
4. A Quick Revision of 5 questions, with **honest** confidence ratings
5. Read the Session Summary
6. Optional: Explain It My Way on one answer, and Misconceptions
